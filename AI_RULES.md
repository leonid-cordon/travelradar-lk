  Решение — добавить в начало промпта:

  ## КРИТИЧЕСКИ ВАЖНО ДЛЯ WINDOWS

  **ЗАПРЕЩЕНО использовать Bash tool для:**
  - Чтения файлов (используй Read)
  - Поиска в файлах (используй Grep)
  - Работы с путями Windows (используй Python через Bash с явными POSIX путями /d/Projects/...)

  **РАЗРЕШЕНО использовать Bash только для:**
  - git команд
  - Python скриптов с явной кодировкой UTF-8
  - Простых команд без вывода Unicode символов

  **Правила Python в Bash:**
  1. Всегда указывай encoding='utf-8' при открытии файлов
  2. НЕ используй Unicode символы в print (✓, ✗, →) — только ASCII
  3. Пути к файлам пиши через / или POSIX формат /d/Projects/...

  **Если команда упала с ошибкой 2 раза подряд:**
  - ОСТАНОВИ выполнение
  - Спроси пользователя, продолжать ли
  - Предложи альтернативный путь через Read/Edit

  **Экономия токенов:**
  - Не повторяй одну и ту же ошибку больше 2 раз
  - Используй Read вместо Bash для чтения файлов
  - Группируй проверки в один Python скрипт
