Задача: выполнять SEO-аудит сайта по файлу состояния seo-audit-state.json батчами по 10 URL.

---

1. ИСТОЧНИК

— использовать файл:
seo-audit-state.json

— формат:
[
{ "url": "...", "status": "pending" },
{ "url": "...", "status": "done" }
]

---

2. ЗАГРУЗКА ДАННЫХ

— прочитать seo-audit-state.json
— сформировать массив объектов

---

3. ВЫБОР БАТЧА

— выбрать первые 10 элементов, где:
status = "pending"

— если осталось меньше 10 → взять все оставшиеся

— если pending = 0:
вывести:
"Аудит завершён"
и остановиться

---

4. ЧТО ПРОВЕРЯТЬ

Для каждой страницы:

— Title (есть / нет / длина)
— Meta description (есть / нет)
— H1 (1 / несколько / нет)
— Canonical (есть и корректный)
— og:url (совпадает с canonical)
— JSON-LD @id (совпадает с canonical)
— lang + og:locale (соответствие)
— noindex (если есть)
— внутренние ссылки (битые / без .html)

---

5. ФОРМАТ ВЫВОДА

URL: https://...

STATUS: OK / ISSUE

Если ISSUE:
— максимум 5 коротких пунктов

---

6. ОБНОВЛЕНИЕ JSON (КЛЮЧЕВОЕ)

После анализа КАЖДОГО URL:

— найти этот URL в массиве
— изменить:

status = "done"

---

7. СОХРАНЕНИЕ

— сохранить файл:
seo-audit-state.json

— полностью перезаписать файл (с обновлёнными статусами)

---

8. ЛОГ (опционально)

— можно дополнительно писать краткий лог в консоль
— файл логов НЕ использовать как источник истины

---

9. ПОВЕДЕНИЕ

— обработать ТОЛЬКО 10 URL
— остановиться

Если пользователь пишет:
"дальше"

→ выполнить следующий батч

---

10. ЗАПРЕЩЕНО

— не использовать sitemap
— не анализировать старые логи
— не считать строки
— не пытаться “угадывать” прогресс

---

11. ЦЕЛЬ

— пройти весь JSON
— каждый URL должен стать status = "done"
— без дублей
— без повторной проверки

---

НАЧНИ СЕЙЧАС:

— прочитай seo-audit-state.json
— выбери 10 URL со статусом pending
— выполни аудит
— обнови их на status = done
— сохрани файл
— остановись

12. КРИТИЧЕСКОЕ ОГРАНИЧЕНИЕ

— НЕ писать PowerShell, Python, JS или любой другой код
— НЕ выполнять скрипты
— НЕ создавать функции
— НЕ использовать терминал

— выполнять анализ ТОЛЬКО напрямую:
  читать HTML → извлекать данные → выводить результат

— ответ должен быть только в формате аудита

Любая попытка писать или выполнять код — ЗАПРЕЩЕНА
ДОПОЛНЕНИЕ (ОБЯЗАТЕЛЬНО):

После обработки батча:

1. обновить статусы в seo-audit-state.json (pending → done)

2. ДОПИСАТЬ результаты в файл:
seo-audit-log.md

Формат:

## Batch — YYYY-MM-DD HH:MM

URL: ...
STATUS: ...
— проблема
— проблема

(для всех URL батча)

НЕ перезаписывать файл, только дописывать в конец.
