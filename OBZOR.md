> Дата составления: **27 марта 2026**

---

## 1. Общая характеристика

**Travel Radar LK** — контентный туристический сайт, ориентированный на русскоязычную, украиноязычную и англоязычную аудиторию. Тематика — практические советы путешественникам: выбор отеля, информация о странах (Египет, Турция), авиаперелёты, лайфхаки, безвизовые направления.

Сайт не является агрегатором или сервисом бронирования. Он строится на качественном редакционном контенте: полноценные статьи с советами, структурированными разделами, чек-листами и иллюстрациями. Монетизация предполагается через партнёрские ссылки (Booking.com) и рекламу.

## 2. Технический стек

| Параметр | Значение |
|---|---|
| HTML | Чистый, без шаблонизаторов |
| CSS | Vanilla CSS, без фреймворков |
| JavaScript | Минимально — динамическая загрузка header/footer |
| Сборщики | Нет (Webpack, Vite — не используются) |
| Фреймворки | Нет (React, Vue — не используются) |
| SSR | Нет — исключительно статический фронтенд |
| Шрифты | Google Fonts: **Inter** + **Playfair Display** |
| Темизация | `data-theme` attribute (dark / light) через localStorage |

Главный принцип архитектуры: **«Простота важнее абстракций»**. Сайт легко читается в редакторе без сборки. Все пути — root-relative (`/assets/...`, `/js/...`, `/Partials/...`).

**О чём:** Философский и практический разбор того, почему высокая оценка отеля не является личной гарантией. Ключевая идея — рейтинг отвечает на вопрос «понравилось ли большинству», а не «подойдёт ли это именно вам».

Разделы:
- Как на самом деле работает рейтинг (среднее арифметическое разных аудиторий)
- Главная ошибка туристов
- Почему цена влияет на рейтинг (бюджетный отель с 9.0 ≠ люкс с 9.0)
- Почему 8.5 иногда лучше 9.3
- **Метод трёх совпадений** — ключевой алгоритм статьи (совпадение типа гостей + сезона + ожиданий)
- Мини-алгоритм проверки за 5 минут
- Чек-лист

Акцентный блок «Метод трёх совпадений» выделен кастомным CSS с синей полосой и карточками. Содержит cross-link на страницу Египта.

**Качество написания:** Высокое. Аналитический стиль, не «советы», а концепция. Хорошо отличается от стандартного туристического контента.

## 10. JavaScript

Проект минималистичен в JS:

| Файл | Назначение |
|---|---|
| `/js/load-header.js` | Динамически подгружает header и footer из `/Partials/` через `fetch()`. Определяет язык по URL-пути и подгружает нужную версию. |
| `/assets/js/egypt-scrollspy.js` | Scroll-spy навигация по якорям на странице Египта (`/*/egypt/index.html`). |

Early-init скрипт на каждой странице (инлайн):
```js
(function() {
    const theme = localStorage.getItem('theme') || 'dark';
    document.documentElement.setAttribute('data-theme', theme);
})();
```
Это обеспечивает мгновенное применение темы без мигания.
