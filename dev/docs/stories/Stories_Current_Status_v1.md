## 3. Окончательно принятые решения (не переоткрывать)

- Stories ≠ Content: две ветки, но обязательная взаимоперелинковка.
- Story = одна полная поездка (вылет → возврат), главы по дням + якоря.
- 1 Story = 1 HTML = 1 постоянный URL; хранение плоское, пер-язык
  `{en|ru|ua}/community/stories/<slug>.html`.
- Хранение ≠ навигация (каталоги — только карточки-ссылки, позже).
- Slug: `firstname-initial-YYYY-MM-DD` (дата = начало поездки), lowercase, дефисы.
- Редакционная модель: редакция = `author`, путешественник = `contributor`
  (источник + герой, НЕ автор); Stories — не UGC.
- Phase 1: не в меню, по прямой ссылке, `noindex`, слот под будущий пример Story.
- Собственный CSS раздела разрешён (единый фирменный стиль обязателен).
- Первая страница делается на RU (язык разработки); Hero-CTA = внутренний якорь.
