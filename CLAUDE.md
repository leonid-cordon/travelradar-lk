## Windows Environment

Критически важно:

- Использовать Read для чтения файлов.
- Использовать Grep для поиска.
- Не использовать Bash для навигации по проекту.
- Не использовать команды вида cd /d.
- Для работы с файлами использовать Read/Edit/Write.
- Если Bash-команда дважды завершилась ошибкой, остановиться и запросить подтверждение пользователя.
- Не повторять одинаковые неудачные команды.
